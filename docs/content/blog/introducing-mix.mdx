# Introducing Mix - Your AI Development Companion

We're excited to introduce **Mix**, a revolutionary AI agent platform designed to supercharge your development workflow. Mix brings intelligent assistance directly to your development environment, helping you write better code, understand complex systems, and ship faster.

## What is Mix?

Mix is an AI-powered development platform that combines:

- **Mix Agent**: A powerful backend service that orchestrates AI interactions
- **Mix Playground**: An intuitive UI for interacting with AI assistants
- **SDKs**: TypeScript and Python SDKs for seamless integration

## Key Features

### 🚀 Intelligent Code Assistance

Mix understands your codebase and provides context-aware suggestions, refactoring help, and code explanations.

### 🔧 Multiple AI Providers

Switch seamlessly between different AI providers (OpenAI, Anthropic, etc.) based on your needs and preferences.

### 📁 File Management

Upload and manage files within your sessions, allowing the AI to reference and work with your project files.

### 🔄 Session Management

Create, fork, and manage multiple conversation sessions to organize different tasks and contexts.

## Getting Started

Getting started with Mix is easy:

```bash
# Install Mix Agent
npm install -g mix-agent

# Start the server
mix-agent start
```

Visit our [quickstart guide](/docs/mix-agent/quickstart) to learn more.
