## Installation

```bash
go get github.com/recreate-run/mix-go-sdk
```

For more examples, see the [Mix Go cookbook](https://github.com/recreate-run/mix-cookbooks)

## Quickstart

```go
package main

import (
	"context"
	"fmt"
	"log"

	mix "github.com/recreate-run/mix-go-sdk"
	"github.com/recreate-run/mix-go-sdk/models/operations"
)

func main() {
	ctx := context.Background()

	// Initialize Mix client
	client := mix.New(
		mix.WithServerURL("http://localhost:8088"),
	)

	// Store API key
	_, err := client.Authentication.StoreAPIKey(ctx, operations.StoreAPIKeyRequest{
		APIKey:   "your-api-key",
		Provider: operations.ProviderOpenrouter,
	})
	if err != nil {
		log.Fatal(err)
	}

	// Create a session
	sessionRes, err := client.Sessions.CreateSession(ctx, &operations.CreateSessionRequest{
		Title: mix.String("My First Session"),
	})
	if err != nil {
		log.Fatal(err)
	}

	sessionID := sessionRes.SessionData.ID

	// Start streaming for real-time updates
	streamRes, err := client.Streaming.StreamEvents(ctx, sessionID, nil)
	if err != nil {
		log.Fatal(err)
	}
	defer streamRes.SSEEventStream.Close()

	// Send a message (in a goroutine to not block stream)
	go func() {
		_, err := client.Messages.SendMessage(ctx, sessionID, operations.SendMessageRequestBody{
			Text: "Hello from Go SDK",
		})
		if err != nil {
			log.Printf("Error sending message: %v", err)
		}
	}()

	// Process streaming events
	for streamRes.SSEEventStream.Next() {
		event := streamRes.SSEEventStream.Value()

		switch e := event.(type) {
		case *operations.SSEContentEvent:
			fmt.Print(e.Data.Content)
		case *operations.SSECompleteEvent:
			fmt.Println("\nDone!")
			return
		case *operations.SSEErrorEvent:
			log.Printf("Error: %s\n", e.Data.Error)
			return
		}
	}
}
```

## Client Initialization

### Mix Client

Main SDK client with the following namespaces:

| Namespace | Description | Key Methods |
|-----------|-------------|-------------|
| `Authentication` | Manage provider credentials | `StoreAPIKey()`, `StartOAuthFlow()`, `GetAuthStatus()` |
| `Sessions` | Session management | `CreateSession()`, `ListSessions()`, `ForkSession()`, `ExportSession()` |
| `Messages` | Message operations | `SendMessage()`, `GetSessionMessages()`, `CancelSessionProcessing()` |
| `Streaming` | Real-time SSE events | `StreamEvents()` |
| `Files` | File management | `UploadSessionFile()`, `ListSessionFiles()`, `GetSessionFile()`, `DeleteSessionFile()` |
| `Permissions` | Permission grants | `GrantPermission()`, `DenyPermission()` |
| `Preferences` | User preferences | `GetPreferences()`, `UpdatePreferences()`, `GetAvailableProviders()` |
| `Tools` | Tool status | `GetToolsStatus()`, `ListLLMTools()` |
| `System` | System operations | `HealthCheck()`, `ListMcpServers()`, `GetSystemInfo()` |

**Constructor:**

```go
client := mix.New(
	mix.WithServerURL("http://localhost:8088"),  // Default server URL
	mix.WithClient(httpClient),                   // Custom HTTP client
	mix.WithRetryConfig(retryConfig),            // Retry configuration
)
```

### Server-Sent Events (SSE) Types

**SSEEventStream Structure:**

```go
type SSEEventStream interface {
	Next() bool
	Value() interface{}
	Close() error
}
```

**Event Types:**

The SDK provides strongly-typed event structures for all SSE events:

| Event Type | Description | Key Fields |
|------------|-------------|------------|
| `SSEConnectedEvent` | Connection established | `Event: "connected"` |
| `SSEContentEvent` | AI response chunks | `Data.Content`, `Data.Type` |
| `SSEThinkingEvent` | AI reasoning | `Data.Content` |
| `SSEToolEvent` | Tool usage | `Data.Name`, tool metadata |
| `SSEToolExecutionStartEvent` | Tool started | `Data.ToolName` |
| `SSEToolExecutionCompleteEvent` | Tool completed | `Data.ToolName`, `Data.Result` |
| `SSEPermissionEvent` | Permission request | `Data.ID`, `Data.Action` |
| `SSECompleteEvent` | Processing done | `Data.Done`, `Data.Content` |
| `SSEHeartbeatEvent` | Keep-alive heartbeat | - |
| `SSEErrorEvent` | Error occurred | `Data.Error` |
| `SSEUserMessageCreatedEvent` | User message created | `Data.MessageID` |
| `SSESessionCreatedEvent` | Session created | `Data.SessionID` |
| `SSESessionDeletedEvent` | Session deleted | `Data.SessionID` |
| `SSEToolParameterDeltaEvent` | Tool parameter streaming | `Data.Delta` |

## Advanced Features

### Continuous Conversations

Multi-turn conversations maintain context within a session:

```go
ctx := context.Background()
client := mix.New()

// Create session
session, _ := client.Sessions.CreateSession(ctx, &operations.CreateSessionRequest{
	Title: mix.String("Multi-turn Chat"),
})

sessionID := session.SessionData.ID

// Turn 1
client.Messages.SendMessage(ctx, sessionID, operations.SendMessageRequestBody{
	Text: "What is Go?",
})

// Turn 2 - maintains context from Turn 1
client.Messages.SendMessage(ctx, sessionID, operations.SendMessageRequestBody{
	Text: "Show me an example",
})
```

### Session Forking

Create a new session branching from an existing conversation at any message:

```go
// Fork at message index 5
forkedSession, err := client.Sessions.ForkSession(ctx, sessionID, operations.ForkSessionRequestBody{
	MessageIndex: 5,
	Title:        mix.String("Forked Session"),
})
if err != nil {
	log.Fatal(err)
}

// Forked session contains messages 0-5 from original
// Can now explore alternative conversation paths
```

### Session Rewinding

Delete messages after a specific point in the conversation:

```go
_, err := client.Sessions.RewindSession(ctx, sessionID, operations.RewindSessionRequestBody{
	MessageID:   "msg_123",
	CleanupMedia: mix.Bool(true), // Delete orphaned media files
})
if err != nil {
	log.Fatal(err)
}
```

### Error Handling

```go
import (
	"errors"
	"github.com/recreate-run/mix-go-sdk/models/apierrors"
)

res, err := client.Sessions.CreateSession(ctx, &operations.CreateSessionRequest{
	Title: mix.String("Test"),
})

if err != nil {
	var apiErr *apierrors.APIError
	if errors.As(err, &apiErr) {
		log.Printf("HTTP %d: %s", apiErr.StatusCode, apiErr.Body)
	}

	var errResp *apierrors.ErrorResponse
	if errors.As(err, &errResp) {
		log.Printf("Error type: %s, message: %s",
			errResp.Error.Type,
			errResp.Error.Message)
	}

	log.Fatal(err)
}
```

## Example Usage

### Complete Session Flow

```go
package main

import (
	"context"
	"fmt"
	"log"

	mix "github.com/recreate-run/mix-go-sdk"
	"github.com/recreate-run/mix-go-sdk/models/operations"
)

func main() {
	ctx := context.Background()
	client := mix.New(mix.WithServerURL("http://localhost:8088"))

	// Create session
	session, err := client.Sessions.CreateSession(ctx, &operations.CreateSessionRequest{
		Title: mix.String("Data Analysis"),
	})
	if err != nil {
		log.Fatal(err)
	}

	sessionID := session.SessionData.ID

	// Stream events
	streamRes, err := client.Streaming.StreamEvents(ctx, sessionID, nil)
	if err != nil {
		log.Fatal(err)
	}
	defer streamRes.SSEEventStream.Close()

	// Send message
	go func() {
		_, err := client.Messages.SendMessage(ctx, sessionID, operations.SendMessageRequestBody{
			Text: "Analyze this dataset",
		})
		if err != nil {
			log.Printf("Error: %v", err)
		}
	}()

	// Process events
	for streamRes.SSEEventStream.Next() {
		event := streamRes.SSEEventStream.Value()

		if contentEvent, ok := event.(*operations.SSEContentEvent); ok {
			fmt.Print(contentEvent.Data.Content)
		}
	}
}
```

### Concurrent Processing

Go's concurrency primitives make it easy to handle multiple sessions:

```go
import "sync"

func processMultipleSessions(client *mix.Mix, queries []string) {
	var wg sync.WaitGroup

	for _, query := range queries {
		wg.Add(1)
		go func(q string) {
			defer wg.Done()

			ctx := context.Background()

			// Create session
			session, err := client.Sessions.CreateSession(ctx, &operations.CreateSessionRequest{
				Title: mix.String(q),
			})
			if err != nil {
				log.Printf("Error creating session: %v", err)
				return
			}

			// Send message
			_, err = client.Messages.SendMessage(ctx, session.SessionData.ID, operations.SendMessageRequestBody{
				Text: q,
			})
			if err != nil {
				log.Printf("Error sending message: %v", err)
			}
		}(query)
	}

	wg.Wait()
}
```

### Context-Based Cancellation

```go
import "time"

// Create context with timeout
ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()

streamRes, err := client.Streaming.StreamEvents(ctx, sessionID, nil)
if err != nil {
	log.Fatal(err)
}
defer streamRes.SSEEventStream.Close()

// Process events with timeout
for streamRes.SSEEventStream.Next() {
	select {
	case <-ctx.Done():
		fmt.Println("Timeout reached")
		return
	default:
		event := streamRes.SSEEventStream.Value()
		// Process event
	}
}
```
