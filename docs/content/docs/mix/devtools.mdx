DevTools is a Tauri desktop application that connects to the Mix Agent backend via the Mix TypeScript SDK.

**Architecture**: `Playground (React/Tauri) → TypeScript SDK → Mix Agent (Go)`

## Quick Start

<Steps>
<Step>

### Launch App

Start Mix Playground desktop application.

<video src="/videos/launch_devtools.mp4" controls loop muted className="w-full rounded-lg" />

</Step>
<Step>

### Configure Provider

1. Click **Settings** icon
2. Choose provider (Anthropic, OpenAI, etc.)
3. Select **OAuth** or **API Key** authentication
4. Complete authentication flow
5. Select a model from available options

<video src="/videos/oauth.mp4" controls loop muted className="w-full rounded-lg" />

</Step>
<Step>

### Start Chatting

Type your message and press Enter to receive AI responses in real-time.

</Step>
</Steps>

## Key Features

- **Real-time AI Chat**: Streaming responses via SSE
- **File Attachments**: Drag & drop files for analysis
- **Session Management**: Create, fork, browse conversations
- **Settings-based Auth**: Configure providers via settings dialog
- **Slash Commands**: Quick actions via `/` commands

### Slash Commands

| Command | Description |
|---------|-------------|
| `/clear` | Start a new session |
| `/sessions` | Browse and switch sessions |
| `/help` | Get assistance and guidance |
| `/mcp` | Model Context Protocol |
| `/permissions` | System permissions and access |
| `/model` | Select provider and model |

**Usage**: Type `/` alone to see all commands, or type `/command` to execute immediately.
