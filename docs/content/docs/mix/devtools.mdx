Tauri desktop app that connects to Mix Agent backend via the Mix TypeScript SDK.

**Architecture**: `Playground (React/Tauri) → TypeScript SDK → Mix Agent (Go)`

## Quick Start

### 1. Launch App
Start Mix Playground desktop application.

### 2. Configure Provider


1. Click **Settings** icon
2. Choose provider (Anthropic, OpenAI, etc.)
3. Select **OAuth** or **API Key** authentication
4. Complete authentication flow
5. Select a model from available options
<video src="/videos/oauth.mp4" controls autoPlay loop muted className="w-full rounded-lg" />

### 3. Start Chatting
Type your message and press Enter. AI responds in real-time.

## Key Features

- **Real-time AI Chat**: Streaming responses via SSE
- **File Attachments**: Drag & drop files for analysis
- **Session Management**: Create, fork, browse conversations
- **Settings-based Auth**: Configure providers via settings dialog
- **Slash Commands**: Quick actions via `/` commands

## Slash Commands

| Command | Description |
|---------|-------------|
| `/clear` | Start a new session |
| `/sessions` | Browse and switch sessions |
| `/help` | Get assistance and guidance |
| `/mcp` | Model Context Protocol |
| `/permissions` | System permissions and access |
| `/model` | Select provider and model |

**Usage**: Type `/` alone to see all commands, or type `/command` to execute immediately.

## Settings & Configuration

### Supported Providers
- **Anthropic** (Claude models)
- **OpenAI** (GPT models)
- **OpenRouter** (Multiple providers)

### Authentication Methods
- **OAuth**: Browser-based secure authentication (recommended)
- **API Key**: Direct key entry from provider dashboard

### Model Selection


1. Authenticate with provider first
2. /model command will display all the providers
3. Provider card shows available models
4. Click model to set as active
<video src="/videos/model_sel.mp4" controls autoPlay loop muted className="w-full rounded-lg" />

## File Attachments

- **Drag & Drop**: Drop files directly into chat
- **Upload Button**: Click attachment icon
- **Reference Files**: Use `@filename` in messages

## Core Components

- **Chat Interface**: Main conversation area
- **Settings Dialog**: Provider auth, model selection, preferences
- **Session Browser**: Navigate between conversations
- **File Upload**: Attach files to conversations
- **Command System**: Slash commands for quick actions

## Troubleshooting

- **No Response**: Check Settings → Provider authentication
- **App Won't Start**: Ensure Mix Agent backend is running
- **Connection Issues**: Verify internet connection
- **Auth Failed**: Check credentials, try again
- **No Models**: Ensure authentication succeeded
