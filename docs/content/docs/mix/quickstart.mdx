## Installation

Install and launch the agent along with the devtools. This is the recommended setup for local testing.

```bash
git clone https://github.com/recreate-run/mix.git
cd mix
make dev
```

## Configuration

Rename the `.env.example` file to `.env` and add your credentials:

```bash
ANTHROPIC_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here
BRAVE_API_KEY=your_key_here
```

- Anthropic API key / Claude code subscription
- Brave API key for web search tool free ([Get free key](https://brave.com/search/api/))
- Gemini API key for `ReadMedia` tool ([Get free key](https://aistudio.google.com/api-keys))

## Run a Demo

Test your installation with a portfolio analysis example:

```bash
cd python_examples
uv sync
uv run demos/portfolio_analysis.py
```

## Troubleshooting

**DevTools won't start?**
- Check port 8088 is not in use: `lsof -i :8088`
- Try `make clean && make dev`

**Authentication failed?**
- Verify API keys are correct
- Check internet connection for OAuth
- Try the alternative auth method

**Need help?** Check [Troubleshooting](/docs/mix/troubleshooting) or open an issue on [GitHub](https://github.com/recreate-run/mix).
