Installing the Mix Python SDK is straightforward. You can use pip or poetry to add it to your project. The SDK is [open source on GitHub](https://github.com/recreate-run/mix-python-sdk).

## Install with pip

```bash
pip install mix-python-sdk
```

## Install with poetry

```bash
poetry add mix-python-sdk
```

## Install from source

You can also install the SDK directly from the source repository:

```bash
pip install git+https://github.com/recreate-run/mix-python-sdk.git
```

## Dependencies

The SDK has minimal dependencies and is designed to work with Python 3.8 and later. It includes:
- Type annotations for improved IDE experience
- HTTP request management
- JSON serialization/deserialization

## Next Steps

Once you've installed the SDK, you can start using it by creating a client. See [Client Creation](/docs/mix/python-sdk/client) for more details.
