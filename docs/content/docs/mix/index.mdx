Mix is an open-source agent SDK built for production web applications. While other tools work only locally, Mix handles the full journey from development to deployment—automated Supabase integration sets up cloud infrastructure in one command, first-party DevTools provide visual debugging and optimization, and multi-model routing uses the best AI for each task (Gemini for vision, Claude for reasoning, OpenAI for search).

## Why Mix?

- **Production-Ready** - Automated Supabase integration for cloud deployment (authentication, storage, database)
- **Visual DevTools** - First-party debugging tools for inspecting agent reasoning, optimizing prompts, and managing context
- **Multi-Model Routing** - Automatically use the best model for each task (Gemini for vision, Claude for reasoning, OpenAI for search)
- **HTTP-First** - RESTful API enables simultaneous DevTools, CLI, and web clients
- **Open Source** - Apache 2.0 license, fully open and free to use
