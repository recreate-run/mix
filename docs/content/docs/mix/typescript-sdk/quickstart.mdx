To interact with the Mix server, you need to create a client instance. The client provides access to all the available API endpoints.

```npm
npm i mix-typescript SDK
```


## Basic Client Creation

Create a new file in the folder  '/src/lib' and add this

```tsx title="src/lib/mix-sdk.ts"
import { Mix } from 'mix-typescript-sdk';

const client = new Mix({
  serverURL: 'http://localhost:8088',
});
```

Then import and use it in your application:

```typescript
// In your application code
import mix from './lib/mix-sdk';

// Use the client
const sessions = await mix.sessions.list();
console.log(sessions)
```
