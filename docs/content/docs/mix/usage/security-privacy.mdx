## What We Actually Track 

### 1. User Messages
- Your prompts
- Session ID (anonymous identifier)
- AI model used

### 2. AI Responses
- Assistant responses
- Session ID (anonymous identifier)
- AI model used
- Provider-specific metrics
  - Response time
  - Token usage

### 3. Tool Usage
- Tool names (e.g., Bash, Read)
- Tool inputs (command parameters)
- Success/failure status
- Error messages (if tools fail)

### 4. Provider Authentication
- Provider name
- Authentication method (api_key, oauth)
- Success/failure status
- No API keys or credentials are ever collected

### 5. Session Lifecycle
- Session creation (title, custom prompt settings)
- Session deletion (age, message count, cost)
- Session rewind (messages deleted, media cleanup)
- Session export (message count, cost, total tokens)

### 6. File Operations
- File uploads (file size, file type, media indicator)
- File deletions (file name, existence status)
- No actual file contents are collected

### 7. Video Exports
- Export settings (FPS, aspect ratio, height, duration)
- Upload status (S3)
- Export duration

### 8. User Preferences
- Preference updates (fields changed, provider/model settings)
- Preference resets (previous settings)

**Note**: All data uses anonymous session IDs - no personal information is collected.

## How to Opt Out

```bash
export MIX_ANALYTICS_ENABLED=false
```

## Frequently Asked Questions

### Is my data used to train AI models?
No. We don't train AI models. Data helps improve Mix's workflow features only.

### Can I use Mix completely privately?
Yes. Disable analytics and no data is collected while keeping full functionality.
