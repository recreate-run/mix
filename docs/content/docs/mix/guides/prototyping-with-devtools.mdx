Mix DevTools provides an interactive desktop application for testing and prototyping AI agents with real-time feedback and debugging capabilities.

## Quick Start

<Steps>
<Step>

### Launch App

Start Mix Playground desktop application.

</Step>

<Step>

### Configure Provider

1. Click **Settings** icon
2. Choose provider (Anthropic, OpenAI, etc.)
3. Select **OAuth** or **API Key** authentication
4. Complete authentication flow
5. Select a model from available options

<video src="/videos/oauth.mp4" controls loop muted className="w-full rounded-lg" />

</Step>

<Step>

### Start Chatting

Type your message and press Enter. AI responds in real-time.

</Step>
</Steps>
