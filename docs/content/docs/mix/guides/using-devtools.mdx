## Realtime Visualization

<Steps>
<Step>

### Launch App

Start Mix and open the browser-based DevTools interface.

Clone the Mix repository and start the development server:

```bash
git clone https://github.com/recreate-run/mix.git
cd mix
make dev
```

This will start the backend and automatically open DevTools in your browser.


</Step>
<Step>

### Configure Provider

1. Click **Settings** icon
2. Choose provider (Anthropic, OpenAI, etc.)
3. Select **OAuth** or **API Key** authentication
4. Complete authentication flow
5. Add Brave Search Api Key for web search tool
6. Add Gemini Api Key for read media tool
