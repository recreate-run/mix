## Overview

This guide walks you through configuring Supabase as your storage backend for Mix using an automated setup script.

<Steps>
<Step>

### Create a Supabase Project

Register a new account at [supabase.com](https://supabase.com) or sign in. Create a project with a name, database password, and region. Setup completes in 1-2 minutes.

<video src="/videos/supabase_project_creation.mp4" controls loop muted className="w-full rounded-lg" />

</Step>

<Step>

### Run the Setup Script

Execute the automated setup script from your project root. The script handles CLI installation, authentication, project selection, and `.env` configuration.

```bash
./scripts/setup-supabase.sh
```

<video src="/videos/setup_supabase.mp4" controls loop muted className="w-full rounded-lg" />

</Step>
</Steps>

## Next Steps

Start the development server with `make dev` to begin using Supabase storage in Mix.
