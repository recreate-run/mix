## Overview

Settings dialog manages all playground configuration. Access via Settings icon or gear button.

## Provider Authentication

### Supported Providers
- **Anthropic** (Claude models)
- **OpenAI** (GPT models)  
- **OpenRouter** (Multiple providers)
- **Google** (Gemini models)

### Authentication Methods
- **OAuth**: Browser-based secure authentication
- **API Key**: Direct key entry from provider dashboard

### Setup Process
1. Open Settings dialog
2. Find provider card  
3. Choose auth method (OAuth/API Key)
4. Complete authentication flow
5. Provider status shows ✅ when successful

## Model Selection

### How to Select Models
1. Authenticate with provider first
2. Provider card shows available models
3. Click model to set as active
4. Current model marked with ⭐

### Model Types
- **Main Agent**: Primary conversation model
- **Sub Agent**: Specialized tasks (auto-synced)
- **Web Search**: For search-enabled workflows
- **Multimodal**: Image/video analysis

## Advanced Settings

### Tool Configuration
- **Web Search Tools**: Enable/disable search capabilities
- **Multimodal Analyzers**: Configure media analysis
- **Permission Defaults**: Set tool execution preferences

### Interface Preferences  
- **Theme**: Dark/light mode
- **Notifications**: Response alerts
- **Auto-update**: Application updates

## Quick Setup

1. **Settings** → **Provider Authentication**
2. **Choose Provider** (e.g., OpenAI)
3. **Select Method** (OAuth recommended)
4. **Authenticate** via browser or API key
5. **Select Model** from available options
6. **Ready to chat**

## Troubleshooting

- **Auth Failed**: Check credentials, try again
- **No Models**: Ensure authentication succeeded  
- **Settings Not Saving**: Restart application
