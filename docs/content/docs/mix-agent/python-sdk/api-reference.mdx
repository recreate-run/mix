The Mix Python SDK provides access to all API endpoints through a set of modules. Each module contains methods that correspond to specific API operations. Both synchronous and asynchronous versions are available for all operations.

## Available Modules

The SDK is organized into the following modules:

- `sessions` - Session management
- `messages` - Message handling
- `auth` - Authentication operations
- `authentication` - Authentication status
- `files` - File operations
- `permissions` - Permission management
- `preferences` - User preferences
- `system` - System operations

## Sessions

Methods for managing sessions.

### List Sessions

```python
# Synchronous
client.sessions.list() -> list[SessionData]

# Asynchronous
await client.sessions.list() -> list[SessionData]
```

Retrieves a list of all available sessions with their metadata.

### Create Session

```python
# Synchronous
client.sessions.create(title="My Session") -> SessionData

# Asynchronous
await client.sessions.create(title="My Session") -> SessionData
```

Creates a new session with the required title. Each session gets an isolated storage directory.

### Get Session

```python
# Synchronous
client.sessions.get(id="session_id") -> SessionData

# Asynchronous
await client.sessions.get(id="session_id") -> SessionData
```

Retrieves detailed information about a specific session.

### Delete Session

```python
# Synchronous
client.sessions.delete(id="session_id") -> None

# Asynchronous
await client.sessions.delete(id="session_id") -> None
```

Permanently deletes a session and all its data.

### Fork Session

```python
# Synchronous
client.sessions.fork(
    id="session_id", 
    title="Forked Session", 
    message_index=5
) -> SessionData

# Asynchronous
await client.sessions.fork(
    id="session_id", 
    title="Forked Session", 
    message_index=5
) -> SessionData
```

Creates a new session based on an existing session, copying messages up to a specified index.

## Messages

Methods for handling messages within sessions.

### Send Message

```python

    session_id="session_id", 
    content="Hello, Mix!"
) -> MessageData

# Asynchronous
await client.messages.send(
    session_id="session_id", 
    content="Hello, Mix!"
) -> MessageData
```

Sends a new message to a session.

### Get Session Messages

```python
# Synchronous
client.messages.get_session(session_id="session_id") -> list[MessageData]

# Asynchronous
await client.messages.get_session(session_id="session_id") -> list[MessageData]
```

Retrieves all messages for a specific session.

### Cancel Processing

```python
# Synchronous
client.messages.cancel_processing(message_id="message_id") -> None

# Asynchronous
await client.messages.cancel_processing(message_id="message_id") -> None
```

Cancels the processing of a message.

### Get Preferences

```python

client.preferences.get_preferences() -> UserPreferencesResponse

# Asynchronous
await client.preferences.get_preferences() -> UserPreferencesResponse
```

Returns the current user preferences including provider and model settings.

```python

    preferred_provider="anthropic",

# Asynchronous
await client.preferences.update_preferences(
    preferred_provider="anthropic",
    main_agent_model="claude-4-sonnet"

```

Updates the user preferences.

### Get Available Providers

```python
# Synchronous
client.preferences.get_available_providers() -> dict[str, ProviderInfo]

# Asynchronous
await client.preferences.get_available_providers() -> dict[str, ProviderInfo]
```

Returns information about all available providers and their models.

### Reset Preferences

```python
# Synchronous
client.preferences.reset_preferences() -> UserPreferencesResponse

# Asynchronous
await client.preferences.reset_preferences() -> UserPreferencesResponse
```

Resets all user preferences to their default values.

The SDK uses structured data models for all requests and responses:

```python

class SessionData:

# Example of MessageData model

    created_at: str
    # Additional fields...
```
