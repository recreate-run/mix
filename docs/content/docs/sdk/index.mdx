## Common Features

Both SDKs provide:

- Full API coverage for Mix server
- Type-safe interfaces
- Session and message management
- Authentication and permission handling
- User preference configuration
- File operations support
- Comprehensive error handling

## REST API

Both SDKs communicate with the Mix server using a RESTful API. If you need to develop integrations in other languages, you can interact directly with the REST API endpoints that the SDKs use internally.
