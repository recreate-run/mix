# SDK

Type-safe JS/TS client for Mix server.

The Mix JavaScript/TypeScript SDK provides a type-safe client for interacting with the Mix server. Use it to build integrations and control Mix programmatically.

## Features

- Full type-safety with TypeScript
- Access to all Mix API endpoints
- Simplified error handling
- Built-in request/response processing
- [Open source](https://github.com/recreate-run/mix-typescript-sdk) with MIT license
