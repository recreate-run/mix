# Installation

Installing the Mix SDK is straightforward. You can use npm, yarn, or pnpm to add it to your project.

## Install with npm

```bash
npm install mix-typescript-sdk
```

## Install with yarn

```bash
yarn add mix-typescript-sdk
```

## Install with pnpm

```bash
pnpm add mix-typescript-sdk
```

## Dependencies

The SDK has minimal dependencies and is designed to work in both Node.js and browser environments. It has built-in TypeScript types, so no separate type definitions are needed.

## Next Steps

Once you've installed the SDK, you can start using it by creating a client. See [Client Creation](/docs/sdk/client) for more details.
