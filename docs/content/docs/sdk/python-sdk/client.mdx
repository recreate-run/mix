To interact with the Mix server, you need to create a client instance. The client provides access to all the available API endpoints.

## Basic Client Creation

Create a client instance by importing the `Mix` class from the SDK and providing the server URL:

```python
from mix_python_sdk import Mix

client = Mix(server_url="http://localhost:8088")
```

## Configuration Options

The `Mix` constructor accepts several configuration options:

| Option | Type | Description | Default |
| ------ | ---- | ----------- | ------- |
| `server_url` | str | URL of the Mix server | http://localhost:8088 |
| `timeout_ms` | int | Request timeout in milliseconds | 60000 (60 seconds) |
| `max_retries` | int | Number of retry attempts | 2 |
| `retry_interval_ms` | int | Interval between retries in milliseconds | 50 |

### Example with Options

```python
client = Mix(
    server_url="http://localhost:8088",
    timeout_ms=30000,  # 30 seconds
    max_retries=3,
    retry_interval_ms=100
)
```

## Using the Client

The Mix Python SDK provides both synchronous and asynchronous interfaces. Here's how to use both:

### Synchronous Usage

```python
# Using the client directly
sessions = client.sessions.list()
print(f"Found {len(sessions)} sessions")

# Using the client with a context manager (recommended)
with Mix(server_url="http://localhost:8088") as client:
    sessions = client.sessions.list()
    print(f"Found {len(sessions)} sessions")
```

### Asynchronous Usage

```python
import asyncio

async def main():
    # Create an async client
    async with Mix(server_url="http://localhost:8088") as client:
        sessions = await client.sessions.list()
        print(f"Found {len(sessions)} sessions")

# Run the async function
asyncio.run(main())
```

## Setting Provider and Model

After creating your client, you can select your preferred AI provider and model:

```python
# Synchronous
client.preferences.update_preferences(
    preferred_provider="anthropic",  # or 'openai', 'openrouter'
    main_agent_model="claude-4-sonnet"  # model ID
)

# Asynchronous
await client.preferences.update_preferences(
    preferred_provider="anthropic",
    main_agent_model="claude-4-sonnet"
)
```

This ensures that your requests use the appropriate AI model for your needs.

## Error Handling

The SDK provides structured error handling:

```python
try:
    client.sessions.list()
except Exception as e:
    print(f"Error: {e}")
    # You can access specific error details if available
    if hasattr(e, "status_code"):
        print(f"Status code: {e.status_code}")
    if hasattr(e, "error_message"):
        print(f"Error message: {e.error_message}")
```
