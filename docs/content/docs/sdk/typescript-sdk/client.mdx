# Creating a Client

To interact with the Mix server, you need to create a client instance. The client provides access to all the available API endpoints.

## Basic Client Creation

Create a client instance by importing the `Mix` class from the SDK and providing the server URL:

```typescript
import { Mix } from 'mix-typescript-sdk';

const client = new Mix({
  serverURL: 'http://localhost:8088',
});
```

## Configuration Options

The `Mix` constructor accepts several configuration options:

| Option | Type | Description | Default |
| ------ | ---- | ----------- | ------- |
| `serverURL` | string | URL of the Mix server | http://localhost:8088 |
| `fetch` | function | Custom fetch implementation | globalThis.fetch |
| `throwOnError` | boolean | Throw errors instead of returning them | false |
| `timeout` | number | Request timeout in milliseconds | 60000 (60 seconds) |

### Example with Options

```typescript
const client = new Mix({
  serverURL: 'http://localhost:8088',
  throwOnError: true,
  timeout: 30000, // 30 seconds
});
```

## Singleton Pattern

In most applications, you'll want to create a single client instance and reuse it throughout your application:

```typescript
// lib/mix-sdk.ts
import { Mix } from 'mix-typescript-sdk';
import { getBackendUrl } from './utils';

// Create a singleton SDK instance configured for our backend
export const mix = new Mix({
  serverURL: getBackendUrl(),
});

export default mix;
```

Then import and use it in your application:

```typescript
// In your application code
import mix from './lib/mix-sdk';

// Use the client
const sessions = await mix.sessions.list();
```

## Setting Provider and Model

After creating your client, you can select your preferred AI provider and model:

```typescript
async function selectProviderAndModel() {
  // Set preferred provider and model
  await client.preferences.updatePreferences({
    preferred_provider: 'anthropic', // or 'openai', 'openrouter'
    main_agent_model: 'claude-4-sonnet' // model ID
  });
  
  console.log('Provider and model selected successfully');
}
```

This ensures that your requests use the appropriate AI model for your needs.
