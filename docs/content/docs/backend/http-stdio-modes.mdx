# HTTP API

Mix provides a REST API interface for programmatic integration and automation.

## HTTP Server Mode

Start Mix as an HTTP server to expose JSON-RPC APIs and media endpoints.

### Quick Start

Start HTTP server on port 8080: `./mix --http-port 8080`  
Custom host and port: `./mix --http-host 0.0.0.0 --http-port 3000`

### HTTP Endpoints Reference

#### Core API Endpoints

| Endpoint | Method | Purpose | Content Type |
|----------|--------|---------|--------------|
| `/health` | GET | Monitor server status and service health | `application/json` |
| `/api/sessions` | GET | List all sessions | `application/json` |
| `/api/sessions` | POST | Create a new session | `application/json` |
| `/api/sessions/{id}` | GET | Get session details | `application/json` |
| `/api/sessions/{id}/messages` | GET | List session messages | `application/json` |
| `/api/sessions/{id}/messages` | POST | Send message to session | `application/json` |
| `/api/auth/login` | POST | OAuth authentication | `application/json` |

### Core Endpoints

#### Sessions API
Manage chat sessions with stateless REST endpoints. All operations require explicit session IDs.

#### Messages API  
Send messages and retrieve conversation history from specific sessions.

#### Authentication API
OAuth-based authentication for secure API access.

#### Health Check
Monitor server status and dependencies at `/health` endpoint.

## Usage Examples

### List Sessions
```bash
curl http://localhost:8088/api/sessions
```

### Create Session
```bash
curl -X POST http://localhost:8088/api/sessions \
  -H "Content-Type: application/json" \
  -d '{"title": "My Session"}'
```

### Send Message  
```bash
curl -X POST http://localhost:8088/api/sessions/{id}/messages \
  -H "Content-Type: application/json" \
  -d '{"content": "Hello, Mix!"}'
```
