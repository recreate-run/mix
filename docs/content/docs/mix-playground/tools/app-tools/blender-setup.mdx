# Blender MCP Integration Setup Guide

Mix integrates with Blender through the **Blender MCP (Model Context Protocol)** to provide AI-powered 3D modeling and professional video editing capabilities. This guide covers the complete setup process.

## Prerequisites

Before starting, ensure you have:

- **Mix** properly installed and configured
- **Blender 3.0+** installed on your system  
- **uv package manager** installed
- **Python 3.10+** (for the MCP server)

## Installation Steps

### 1. Install Required Dependencies

#### Install uv Package Manager

**On macOS:**
```bash
brew install uv
```

**On Windows:**
```bash
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**On Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

#### Install Blender-MCP Package

```bash
uv tool install blender-mcp
```

### 2. Clone the Blender MCP Repository

Clone the official Blender MCP repository for the addon:

```bash
git clone https://github.com/ahujasid/blender-mcp.git
```

### 3. Install the Blender Addon

1. **Copy the addon file:**
   ```bash
   cp blender-mcp/addon.py ~/Downloads/
   ```

2. **Install in Blender:**
   - Open Blender
   - Go to **Edit > Preferences > Add-ons**
   - Click **"Install..."** and select `~/Downloads/addon.py`
   - Enable the addon by checking **"Interface: Blender MCP"**

3. **Start the MCP server in Blender:**
   - Press `N` to open the sidebar if not visible
   - Find the **"BlenderMCP"** tab
   - Click **"Connect to Claude"** (this starts the server on port 9876)

### 4. Configure Mix for Blender MCP

Create or edit your `.mix.json` file in your project root directory:

```json
{
  "agents": {
    "main": {
      "model": "claude-4-sonnet",
      "maxTokens": 4096
    },
    "sub": {
      "model": "claude-4-sonnet", 
      "maxTokens": 2048
    }
  },
  "mcpServers": {
    "blender": { 
      "type": "stdio",
      "command": "uv",
      "allowedTools": ["execute_blender_code"],
      "args": [
        "--directory",
        "/path/to/your/blender-mcp/src/blender_mcp",
        "run",
        "server.py"
      ],
      "env": []
    }
  }
}
```

**Important**: Replace `/path/to/your/blender-mcp` with the actual path where you cloned the repository.

### 5. Verify Installation

To verify that Mix can communicate with Blender MCP:

1. **Ensure Blender MCP server is running:**
   - Blender is open with the addon enabled
   - The "Connect to Claude" button shows active connection

2. **Test the integration:**
   ```bash
   # Test with a simple 3D modeling command
   ./mix -p "Create a red cube in Blender"
   ```

3. **Check the logs:**
   ```bash
   make tail-log
   ```
   
   You should see logs indicating successful MCP connection and tool loading.

## How It Works

The Blender MCP integration uses a sophisticated architecture:

1. **Blender Addon**: Creates a socket server (port 9876) within Blender
2. **MCP Server**: Python server that implements the Model Context Protocol
3. **Mix Integration**: Connects to the MCP server via `uvx blender-mcp`
4. **Tool Filtering**: Only `execute_blender_code` tool is exposed for security

## Configuration Options

### MCP Server Configuration

```json
{
  "mcpServers": {
    "blender": {
      "type": "stdio",              // Communication method
      "command": "uv",              // Command to run MCP server
      "allowedTools": [...],        // Whitelist of allowed tools
      "deniedTools": [...],         // Blacklist of denied tools
      "env": [...]                  // Environment variables
    }
  }
}
```

### Environment Variables

Optional environment variables for Blender connection:

- `BLENDER_HOST`: Socket server host (default: "localhost")
- `BLENDER_PORT`: Socket server port (default: 9876)

## Troubleshooting

### Common Issues

1. **"Connection refused" errors:**
   - Ensure Blender is running with the MCP addon enabled
   - Check that the MCP server is active (green indicator in Blender sidebar)
   - Verify port 9876 is not blocked by firewall

2. **"MCP servers count=0" in logs:**
   - Check that `.mix.json` is in the correct directory (project root)
   - Verify the JSON syntax is valid
   - Ensure the blender-mcp path is correct

3. **"Tool filtered out" messages:**
   - Check the `allowedTools` configuration
   - Ensure `execute_blender_code` is in the allowed list

4. **Timeout errors:**
   - Blender may be busy with another operation
   - Try breaking complex requests into smaller steps
   - Increase timeout in MCP configuration if needed

### Debug Steps

1. **Test MCP server manually:**
   ```bash
   uvx blender-mcp
   ```
   Should show successful connection to Blender.

2. **Check configuration loading:**
   ```bash
   make tail-log | grep -i "mcp\|blender"
   ```

3. **Verify Blender addon status:**
   - Check BlenderMCP sidebar in Blender
   - Look for "Connected" status indicator

## Best Practices

### For 3D Modeling
1. **Start Simple**: Begin with basic shapes and gradually add complexity
2. **Use Clear Descriptions**: Be specific about materials, colors, and positioning
3. **Save Frequently**: Blender projects should be saved regularly
4. **Check Results**: Use viewport screenshots to verify changes

### For Video Editing
1. **Organize Assets**: Keep media files in organized directories
2. **Use Absolute Paths**: Always provide full file paths
3. **Channel Management**: Use different channels for different media types
4. **Export Settings**: Specify resolution, framerate, and codec preferences

## Advanced Configuration

### Custom Tool Selection

You can customize which Blender MCP tools are available:

```json
{
  "mcpServers": {
    "blender": {
      "allowedTools": [
        "execute_blender_code",
        "get_scene_info",
        "get_viewport_screenshot"
      ]
    }
  }
}
```

### Multiple Blender Instances

For advanced workflows, you can configure multiple Blender instances:

```json
{
  "mcpServers": {
    "blender-modeling": {
      "type": "stdio",
      "command": "uv",
      "args": ["--directory", "/path/to/blender-mcp-1", "run", "server.py"],
      "env": ["BLENDER_PORT=9876"]
    },
    "blender-rendering": {
      "type": "stdio", 
      "command": "uv",
      "args": ["--directory", "/path/to/blender-mcp-2", "run", "server.py"],
      "env": ["BLENDER_PORT=9877"]
    }
  }
}
```

## Security Considerations

- The `execute_blender_code` tool allows running arbitrary Python code in Blender
- Always review AI-generated code before execution in production
- Use tool filtering to limit available capabilities
- Consider running Blender in isolated environments for untrusted content
