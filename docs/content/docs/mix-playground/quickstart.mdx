## 3-Step Setup

### 1. Launch App
Start Mix Playground desktop application.

### 2. Configure Provider  
1. Click **Settings** icon
2. Choose provider (Anthropic, OpenAI, etc.)
3. Select **OAuth** or **API Key** authentication
4. Complete authentication flow
5. Select a model from available options

### 3. Start Chatting
Type your message and press Enter. AI responds in real-time.

## First Commands

```bash
/help        # Show available commands
/sessions    # Browse conversations  
/clear       # Start new session
/status      # Check authentication
```

## File Attachments

- **Drag & Drop**: Drop files into chat
- **Upload Button**: Click attachment icon
- **Reference Files**: Use `@filename` in messages

## Tips

- **Settings Dialog**: All configuration happens here
- **Real-time Responses**: Messages stream live
- **Multiple Sessions**: Switch between conversations
- **Slash Commands**: Quick actions with `/`

## Troubleshooting

- **No Response**: Check Settings → Provider authentication
- **App Won't Start**: Ensure Mix Agent backend is running
- **Connection Issues**: Verify internet connection

That's it! You're ready to use Mix Playground.
